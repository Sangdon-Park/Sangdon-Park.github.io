6장 동적 계획법

6-1 피보나치 수 · 아주 쉬움

앞의 두 수를 더해서 다음 수를 만듭니다.

처음 두 수는 0, 1입니다.
그다음은 1, 2, 3, 5, 8, 13입니다.

n=7이면 7번 칸의 값 13을 반환합니다. 번호는 0부터 셉니다.

fib_bottomup(n)

전체 문제와 입력 조건

피보나치 수는 0, 1로 시작하고, 그다음부터는 바로 앞의 두 수를 더해 만듭니다. 번호를 0부터 세므로 F(0)=0, F(1)=1, F(2)=1입니다. 정수 n(0~90)을 받아 n번째 값 F(n)을 반환하세요. 예를 들어 n=7의 답은 13입니다. C의 반환형은 long long입니다.

6-2 인접하지 않은 수의 최대 합 · 쉬움

붙어 있는 두 수를 함께 고르지 않고 합을 가장 크게 만듭니다.

배열이 [1, 3, 1, 5]라면 3과 5를 고를 수 있습니다.
두 수 사이에 1이 있으므로 서로 붙어 있지 않습니다.

가능한 최대 합 3+5=8을 반환합니다. 아무것도 고르지 않아도 됩니다.

nonadjacent(a)

전체 문제와 입력 조건

정수 배열 a에서 몇 개의 수를 고릅니다. 바로 붙어 있는 두 원소는 함께 고를 수 없습니다. 고른 수의 합이 가장 커지게 하세요. 배열 길이는 0~10,000, 각 값은 −1,000,000~1,000,000입니다. 아무것도 고르지 않아도 되고, 이때 합은 0입니다. 가능한 최대 합을 반환하세요. 배열의 순서는 바꾸지 않습니다. 예를 들어 [1,3,1,5]에서는 3과 5를 골라 8을 반환합니다.

이 문제 연습하기

6-3 1로 만들기 · 기본

정수 하나를 1로 바꾸는 데 필요한 최소 연산 횟수를 구합니다.

한 번에 1을 빼거나, 딱 나누어떨어지면 2·3·5로 나눕니다.
10은 5를 거쳐 1로 가면 두 번입니다.

10÷2=5, 5÷5=1이므로 2를 반환합니다.

make_one(n)

전체 문제와 입력 조건

정수 n을 1로 바꾸려고 합니다. 한 번에 다음 중 하나를 합니다: 1 빼기, 또는 나누어떨어질 때만 2·3·5 중 하나로 나누기. n은 1~10,000입니다. 필요한 연산 횟수의 최솟값을 반환하세요. 처음부터 1이면 0입니다. 예를 들어 10은 10,5,1로 두 번에 바꿀 수 있습니다.

이 문제 연습하기

6-4 0/1 배낭 · 조금 도전

무게 제한을 지키면서 물건의 가치 합을 가장 크게 만듭니다.

배낭은 5kg까지 담습니다.
A는 2kg·3점, B는 3kg·4점, C는 4kg·5점입니다.

A와 B를 고르면 5kg·7점입니다. 최대 가치 7을 반환합니다.

knapsack2(items, W)

전체 문제와 입력 조건

배낭에 물건을 담되 무게 합이 용량 W를 넘으면 안 됩니다. 물건마다 하나씩만 있고 쪼갤 수 없습니다. 물건은 [무게, 가치] 쌍의 배열 items로 주어집니다. 담을 수 있는 물건들의 가치 합 중 최댓값을 반환하세요. 아무것도 안 담아도 됩니다. 물건 수는 0~100, W는 0~1000, 각 무게는 1~1000, 가치는 0~1,000,000입니다. 예를 들어 [[2,3],[3,4],[4,5]], W=5이면 앞의 두 물건을 담아 7을 반환합니다.

7장 백트래킹 기법

7-1 카드를 순서 있게 고르는 경우의 수 · 아주 쉬움

서로 다른 카드 중 몇 장을 골라 줄 세우는 경우의 수를 셉니다.

카드가 1, 2, 3이고 두 장을 놓습니다.
[1,2]와 [2,1]은 순서가 다르므로 서로 다른 경우입니다.

[1,2], [1,3], [2,1], [2,3], [3,1], [3,2]의 6가지를 반환합니다.

permutation_count(n, r)

전체 문제와 입력 조건

1부터 n까지 적힌 서로 다른 카드 n장 중 r장을 골라 한 줄로 놓습니다. 같은 카드를 두 번 쓰지 않습니다. 순서가 다르면 다른 경우입니다. 0≤r≤n≤8입니다. 가능한 경우의 수를 반환하세요. r=0이면 아무것도 놓지 않은 한 가지로 셉니다. 예를 들어 n=3, r=2이면 [1,2]와 [2,1]을 다르게 세어 총 6가지입니다.

이 문제 연습하기

7-2 합이 목표인 부분집합의 개수 · 쉬움

몇 개의 수를 골라 합이 목표와 같아지는 경우를 셉니다.

a=[1,2,3], target=3입니다.
1과 2를 고르는 방법, 3만 고르는 방법이 있습니다.

가능한 선택이 두 개이므로 2를 반환합니다.

subset_sum_count(a, target)

전체 문제와 입력 조건

양의 정수 배열 a에서 몇 개를 골라 합이 target과 같아지는 경우의 수를 반환하세요. 각 위치의 원소는 한 번만 고릅니다. 값이 같아도 위치가 다르면 다른 원소입니다. 배열 길이는 0~20, 각 값은 1~50, target은 0~1000입니다. 아무것도 고르지 않은 경우도 셉니다. 예를 들어 [1,2,3], target=3의 답은 1+2와 3만 고르는 두 가지입니다.

이 문제 연습하기

7-3 이웃한 정점을 다른 색으로 칠하기 · 기본

선으로 연결된 두 점의 색을 다르게 칠할 수 있는지 확인합니다.

세 점 A, B, C가 삼각형으로 연결되어 있습니다.
A를 빨강, B를 파랑으로 칠하면 C에는 다른 색이 필요합니다.

세 색이면 가능하므로 1, 두 색이면 불가능하므로 0을 반환합니다.

can_color(graph, k)

전체 문제와 입력 조건

선으로 연결된 두 점을 서로 다른 색으로 칠하려고 합니다. k가지 색으로 모든 점을 칠할 수 있으면 1, 없으면 0을 반환하세요. 점은 1~8개, k는 1~3입니다. 연결은 0/1 표 graph로 줍니다. graph[i][j]=1이면 점 i와 j가 연결되어 있습니다. 무방향이라 표는 대칭이고 대각선은 0입니다. 예를 들어 삼각형은 두 색으로 불가능하고 세 색으로 가능합니다.

이 문제 연습하기

7-4 N-Queen 배치의 수 · 조금 도전

퀸끼리 같은 행·열·대각선에 놓이지 않는 배치 수를 셉니다.

4×4 체스판에 퀸 네 개를 놓습니다.
위에서부터 열 번호를 2,4,1,3으로 고르면 서로 공격하지 않습니다.

4×4의 가능한 배치는 총 두 가지입니다. 2를 반환합니다.

nqueen_count(n)

전체 문제와 입력 조건

n×n 체스판에 퀸 n개를 놓습니다. 두 퀸이 같은 행, 같은 열, 같은 대각선에 놓이면 안 됩니다. 가능한 배치의 수를 반환하세요. n은 1~8입니다. 회전하거나 뒤집은 배치도 놓인 칸이 다르면 따로 셉니다. 예를 들어 n=4의 답은 2입니다.

8장 분기한정 기법

8-1 정해진 순회 경로의 비용 · 아주 쉬움

정해진 도시 방문 순서의 이동 비용을 더합니다.

0,1,2 순서로 방문합니다. 비용은 0→1이 4, 1→2가 2입니다.
마지막 2→0의 비용은 7입니다.

출발점으로 돌아오는 비용까지 4+2+7=13을 반환합니다.

route_cost(dist, route)

전체 문제와 입력 조건

도시 방문 순서 route가 이미 정해져 있습니다. 그 순서로 이동한 뒤 마지막 도시에서 출발 도시 0으로 돌아오는 비용까지 더해 반환하세요. 도시는 1~9개입니다. 비용 표 dist에서 dist[i][j]는 i에서 j로 가는 비용입니다. 모든 이동이 가능하고 비용은 0~100, 대각선은 0입니다. 방향별 비용은 달라도 됩니다. route는 0에서 시작하고 모든 도시 번호 0~n−1을 한 번씩 포함합니다. 도시가 하나이면 0을 반환합니다.

이 문제 연습하기

8-2 남은 작업 비용의 하한 · 쉬움

남은 각 사람의 가장 싼 작업 비용을 더합니다.

0번 사람은 작업 1을 이미 맡았습니다.
남은 1번 사람의 최소 비용은 3, 2번 사람의 최소 비용은 1입니다.

이 계산에서는 같은 작업을 골라도 허용합니다. 3+1=4를 반환합니다.

assignment_bound(cost, used, next_row)

전체 문제와 입력 조건

사람 n명에게 작업 n개를 맡기는 비용 표 cost가 있습니다. 앞의 next_row명은 이미 배정했습니다. used[c]는 작업 c를 이미 맡겼으면 1, 아직이면 0입니다. 남은 각 사람의 행에서 아직 사용하지 않은 작업 중 가장 싼 비용을 찾고, 그 값들을 더해 반환하세요. 이 계산에서는 여러 사람이 같은 작업을 골라도 허용합니다. 예를 들어 남은 두 행의 최솟값이 3과 1이면 4를 반환합니다. 이처럼 실제 남은 최소 비용보다 크지 않게 잡은 값이 하한입니다. n은 1~8, 각 비용은 0~100입니다. used의 1 개수는 next_row와 같습니다. next_row=n이면 남은 사람이 없어 0입니다.

이 문제 연습하기

8-3 작업을 하나씩 배정하는 최소 비용 · 기본

각 사람에게 서로 다른 작업을 하나씩 맡겨 비용을 최소화합니다.

사람 0의 비용은 [4,1], 사람 1의 비용은 [2,3]입니다.
작업 0과 1을 각각 한 번씩만 맡겨야 합니다.

사람0→작업1, 사람1→작업0이면 1+2=3입니다. 3을 반환합니다.

assignment_min(cost)

전체 문제와 입력 조건

사람마다 작업 하나를 맡기고, 각 작업도 한 사람에게만 맡기려고 합니다. 비용의 총합이 가장 작아지게 배정하세요. 사람 n명과 작업 n개의 비용이 n×n 표 cost로 주어집니다. cost[r][c]는 사람 r이 작업 c를 맡을 때의 비용입니다. n은 1~8, 각 비용은 0~100입니다. 가능한 배정의 최소 총비용을 반환하세요. 예를 들어 [[4,1],[2,3]]에서는 사람0에게 작업1, 사람1에게 작업0을 맡겨 3을 반환합니다.

이 문제 연습하기

8-4 모든 도시를 한 번씩 방문하는 최소 순회 비용 · 조금 도전

도시를 모두 한 번씩 방문하고 출발점으로 돌아오는 최소 비용을 구합니다.

네 도시의 방문 순서들을 비교합니다.
0,1,2,3,0은 비용 23이고, 0,1,3,2,0은 비용 10입니다.

가능한 순회 경로들의 비용 중 가장 작은 값을 반환합니다.

tsp_min(dist)

전체 문제와 입력 조건

0번 도시에서 출발해 다른 도시를 각각 한 번 방문하고 0번으로 돌아옵니다. 가능한 방문 순서 중 전체 이동 비용이 가장 작은 값을 반환하세요. 도시는 1~9개이고 비용 표 dist가 주어집니다. dist[i][j]는 i에서 j로 가는 비용이며 0~100입니다. 대각선은 0, 모든 이동은 가능하고 방향에 따라 비용이 달라도 됩니다. 도시가 하나이면 답은 0입니다.

9장 NP완전 문제

9-1 제시된 부분집합 합 확인 · 아주 쉬움

이미 골라 놓은 수들의 합이 목표와 같은지 확인합니다.

a=[1,2,3], selected=[1,0,1], target=4입니다.
표시가 1인 첫째와 셋째 원소를 고른 상태입니다.

1+3=4이므로 맞으면 1을, 다르면 0을 반환합니다.

verify_subset_sum(a, selected, target)

전체 문제와 입력 조건

정수 배열 a와 선택 표시 selected를 받습니다. selected[i]=1인 원소만 더해 합이 target과 같은지 확인하세요. 같으면 1, 다르면 0을 반환합니다. 새로 고를 수를 찾지 않고 주어진 선택을 검사합니다. a의 길이는 0~20, 각 값은 0~100, target은 0~2000입니다. selected는 a와 같은 길이의 0/1 배열입니다. 예를 들어 a=[1,2,3], selected=[1,0,1], target=4이면 1+3=4이므로 1입니다.

이 문제 연습하기

9-2 제시된 정점 커버 확인 · 쉬움

고른 점들이 모든 선을 덮는지 확인합니다.

삼각형의 점 0과 1을 골랐습니다.
선 0–1, 0–2, 1–2는 모두 고른 점과 닿아 있습니다.

모든 선에 고른 끝점이 하나 이상 있으면 1, 아니면 0을 반환합니다.

verify_vertex_cover(graph, selected)

전체 문제와 입력 조건

그래프에서 고른 점들이 모든 선을 덮는지 검사하세요. 각 선의 양 끝 중 적어도 한 점을 골랐으면 그 선을 덮은 것입니다. 전부 덮으면 1, 못 덮은 선이 있으면 0을 반환합니다. 점은 1~8개입니다. graph는 대칭인 0/1 연결 표이고 대각선은 0입니다. selected[i]는 점 i를 골랐으면 1, 아니면 0입니다. 고른 점의 수를 최소화할 필요는 없습니다. 예를 들어 삼각형에서 두 점을 고르면 세 선을 모두 덮습니다.

이 문제 연습하기

9-3 제시된 해밀턴 순회 확인 · 기본

주어진 순서가 모든 점을 한 번씩 지나 출발점으로 돌아오는지 검사합니다.

정점이 0,1,2,3이고 path=[0,1,2,3]입니다.
0–1, 1–2, 2–3뿐 아니라 3–0 선도 있어야 합니다.

빠진 점·중복 점·없는 연결이 모두 없으면 1을 반환합니다.

verify_hamiltonian(graph, path)

전체 문제와 입력 조건

주어진 방문 순서 path가 모든 점을 한 번씩 지나 출발점으로 돌아오는 올바른 순회인지 검사하세요. 맞으면 1, 틀리면 0을 반환합니다. 점의 수 n은 3~8입니다. graph는 대칭인 0/1 연결 표이며 대각선은 0이고, path의 길이는 n입니다. 번호는 0~n−1 안에 있어야 하고 중복이 없어야 합니다. 순서대로 이웃한 두 점 사이와 마지막·첫 점 사이에 모두 선이 있어야 합니다. 범위 밖 번호, 중복, 빠진 연결이 있으면 0입니다.

이 문제 연습하기

9-4 작은 3-CNF 식의 만족 가능성 · 조금 도전

참·거짓 값을 골라 모든 조건을 만족시킬 수 있는지 확인합니다.

x₁은 0(거짓) 또는 1(참) 중 하나입니다.
조건 [1,1,1]은 x₁이 참이어야 통과합니다.
