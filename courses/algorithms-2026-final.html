메모이제이션에 쓰는 해시맵과 Python 사전

해시맵은 키와 값을 짝지어 저장합니다. 계단 높이를 키로, 그 높이까지 오르는 방법 수를 값으로 두면 높이 4에 답 5를 연결할 수 있습니다. Python에서는 dict, 즉 사전을 사용합니다.

memo = {1: 1, 2: 2}  # 1칸은 1가지, 2칸은 2가지
memo[3] = 3             # 높이 3의 답 3을 저장
3 in memo               # True: 키 3이 있음
memo[3]                 # 3: 키 3의 값을 읽음
4 in memo               # False: 아직 키 4는 없음

in으로 키가 있는지 확인한 뒤 값을 읽습니다. 없는 키를 바로 읽으면 KeyError가 발생합니다. 배열의 dp[4]는 번호 4인 칸을 읽고, 사전의 memo[4]는 키 4에 연결한 값을 찾습니다. 아래 문제의 제출 코드는 배열과 변수로 구현할 수 있습니다.

6-2 계단 오르기 · 쉬움

작성 방식: 바텀업(반복문)
작은 높이부터 차례로 표를 채우는 바텀업 방식으로 작성한다. 1칸의 답은 1, 2칸의 답은 2이다. n=1이면 1을 바로 반환하고, 그 외에는 dp[1]=1, dp[2]=2를 넣은 뒤 3부터 n까지 반복문으로 계산한다.

높이가 n칸인 계단을 바닥에서 꼭대기까지 오른다. 한 번에 1칸 또는 2칸을 오를 수 있다. 오르는 순서가 다르면 서로 다른 방법으로 센다.

꼭대기까지 오르는 서로 다른 방법의 수를 반환하시오.

climb_stairs(n)

입력

n
계단 높이. 1 이상 90 이하의 정수

반환값과 조건

오르는 방법의 개수를 정수 하나로 반환한다. 이동 횟수나 이동 순서 목록을 반환하지 않는다.

  • 1칸 뒤 2칸을 오르는 방법과 2칸 뒤 1칸을 오르는 방법은 서로 다르다.
  • 계단을 내려가거나 꼭대기를 넘는 이동은 허용하지 않는다.
  • C에서는 큰 결과를 저장하도록 long long을 사용한다.

예제

한 칸
n=1

반환값: 1

1칸을 한 번 오르는 방법 하나다.

두 칸
n=2

반환값: 2

1+1과 2의 두 가지다.

세 칸
n=3

반환값: 3

1+1+1, 1+2, 2+1의 세 가지다.

네 칸
n=4

반환값: 5

1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2의 다섯 가지다.

일곱 칸
n=7

반환값: 21

5칸의 8가지와 6칸의 13가지를 더해 21가지다.

풀이 설명

마지막 이동이 1칸이면 n-1칸까지 오르는 방법에 1칸을 붙이고, 마지막 이동이 2칸이면 n-2칸까지 오르는 방법에 2칸을 붙인다. 두 경우의 방법 수를 더한다. dp[1]=1, dp[2]=2에서 시작하고, 3칸부터 앞의 두 답을 더한다. n=1이면 1을 바로 반환한다.

C 함수와 자료형
long long climb_stairs(int n)

n은 계단 높이이므로 int로 받는다. 방법 수는 크게 늘어나므로 반환값과 dp 배열의 각 칸에 long long을 쓴다.

6-3 연속 부분합 · 기본

정수 배열 a에서 하나 이상의 원소가 연속해서 이어진 구간 하나를 고른다. 구간 중간의 원소를 건너뛸 수 없다.

고른 구간의 원소 합 중 가장 큰 값을 반환하시오.

max_subarray(a)

입력

a
길이 1~10,000인 정수 배열. 각 값은 -1,000,000~1,000,000

반환값과 조건

연속 구간 합의 최댓값을 정수 하나로 반환한다. 구간의 위치나 원소 목록을 반환하지 않는다.

  • 구간에는 원소가 반드시 하나 이상 있어야 한다. 빈 선택은 허용하지 않는다.
  • 배열의 원래 순서와 이웃 관계를 유지한다.
  • 모든 값이 음수이면 그중 가장 큰 값 하나를 고른다.
  • C에서는 합이 int 범위를 넘을 수 있으므로 long long을 사용한다.

예제

중간부터 끝까지
a=[4,-6,3,2,-1,4]

반환값: 8

3+2-1+4=8인 연속 구간을 고른다.

모두 음수
a=[-8,-3,-5]

반환값: -3

하나는 골라야 하므로 가장 큰 -3을 고른다.

원소 한 개
a=[-7]

반환값: -7

유일한 구간 [-7]의 합 -7을 반환한다.

모두 양수
a=[2,4,1]

반환값: 7

배열 전체를 골라 합 7을 얻는다.

0을 고르는 경우
a=[-2,0,-1]

반환값: 0

원소 0 하나로 이루어진 구간을 고른다.

풀이 설명

ending에는 현재 위치에서 반드시 끝나는 구간의 최대 합을 둔다. 이번 수만으로 새로 시작하거나, 이전 ending에 이번 수를 붙이는 두 후보를 비교한다. best에는 지금까지 본 모든 위치의 최대 합을 따로 남긴다. 두 값은 첫 원소로 시작한다.

C 함수와 자료형
long long max_subarray(const int a[], int n)

a는 원소 배열, n은 원소 수이다. a는 읽기만 한다. n은 1 이상이므로 a[0]으로 시작할 수 있다. 원소의 합은 long long으로 저장한다.

6-4 1로 만드는 최소 연산 횟수 · 도전문제

정수 n을 아래 연산으로 바꾸어 1을 만든다. 한 번의 연산에서는 1을 빼거나, 2·3·5 중 하나로 나눈다. 나눗셈은 나누어떨어질 때만 할 수 있다.

n을 1로 만드는 데 필요한 연산 횟수의 최솟값을 반환하시오.

make_one(n)

입력

n
1 이상 10,000 이하의 정수

반환값과 조건

최소 연산 횟수를 정수로 반환한다. 중간에 거친 수의 개수가 아니라 연산한 횟수를 센다.

  • 처음부터 n=1이면 연산하지 않으므로 답은 0이다.
  • 정수 나눗셈으로 나머지를 버리는 연산은 허용하지 않는다. 예를 들어 7을 2로 나누어 3으로 바꿀 수 없다.

바로 나누는 경우와 먼저 1을 빼는 경우

이미 도착
n=1

반환값: 0

이미 1이므로 연산은 0회이다.

한 번에 도착
n=5

반환값: 1

5÷5=1이다.

두 번 나누기
n=10

반환값: 2

10÷2=5, 5÷5=1로 두 번이다.

먼저 1 빼기
n=26

반환값: 3

26−1=25, 25÷5=5, 5÷5=1로 세 번이다.

처음에 나눌 수 없음
n=7

반환값: 3

7−1=6, 6÷3=2, 2÷2=1로 세 번이다.

나누어떨어지는 후보만 비교한다

10에서는 9, 5, 2로 갈 수 있다. 9에서 1까지는 최소 두 번, 5와 2에서는 각각 한 번이 필요하다. 여기에 첫 이동 한 번을 더하면 후보는 3,2,2회이고 답은 2회이다. 3으로 나누는 경우는 10이 3의 배수가 아니므로 후보에 넣지 않는다.

C 함수의 인자
int make_one(int n, int dp[])

dp는 길이가 n+1인 작업 배열이다. 함수가 dp[1]부터 채운다.

7-2 합이 목표가 되는 선택의 수 · 쉬움

양의 정수 배열 a에서 원소를 몇 개 골라 합을 만든다. 각 위치의 원소는 한 번만 고를 수 있다. 고른 원소의 합이 target과 같은 선택이 몇 개인지 센다.

합이 target인 선택의 수를 정수로 반환하시오.

subset_sum_count(a, target)

입력

a
길이 0~20의 배열. 각 값은 1~50인 정수
target
목표 합. 0~1000의 정수

반환값과 조건

조건을 만족하는 선택의 개수를 반환한다. 가능한지 여부나 선택한 원소의 개수를 반환하지 않는다.

  • 같은 값이라도 위치가 다르면 다른 원소이다.
  • 선택한 원소를 나열하는 순서는 구분하지 않는다. 1과 2를 고른 것과 2와 1을 고른 것은 같은 선택이다.
  • 아무것도 고르지 않은 선택도 포함하며, 그 합은 0이다.

같은 값과 같은 선택을 구분하는 기준

서로 다른 두 선택
a=[1,2,3], target=3

반환값: 2

1과 2를 고르거나, 3만 고르는 두 방법이다.

값이 같은 두 원소
a=[1,1], target=1

반환값: 2

첫 번째 1을 고르는 것과 두 번째 1을 고르는 것은 다르다.

순서는 세지 않음
a=[1,2], target=3

반환값: 1

두 원소를 모두 고르는 한 방법이다. 1+2와 2+1로 두 번 세지 않는다.

빈 선택
a=[], target=0

반환값: 1

아무것도 고르지 않은 한 방법의 합이 0이다.

만들 수 없는 합
a=[2,4], target=3

반환값: 0

가능한 합은 0,2,4,6이다. 3은 없다.

원소 하나마다 두 갈래로 나뉜다

첫 원소 1을 보는 순간에는 고르거나 건너뛰는 두 선택이 있다. 1을 골랐다면 다음 원소 2를 볼 때 합은 1이고, 건너뛰었다면 합은 0이다. 이 과정을 마지막 원소까지 반복하고, 마지막 합이 target인 갈래에서만 1을 더한다.

C 함수의 인자
int subset_sum_count(const int a[], int n, int target)

n은 배열 a의 원소 수이다.

7-3 이웃한 점을 다른 색으로 칠하기 · 기본

무방향 그래프의 각 점에 색 하나를 칠한다. 선으로 연결된 두 점은 서로 다른 색이어야 한다. 사용할 수 있는 색은 1번부터 k번까지이며, 모든 색을 반드시 사용할 필요는 없다.

이 조건으로 모든 점을 칠할 수 있으면 1, 없으면 0을 반환하시오.

can_color(graph, k)

입력

graph
점 1~8개의 0/1 연결 표. graph[i][j]=1이면 i와 j가 연결됨
k
쓸 수 있는 색 수. 1~3의 정수

반환값과 조건

가능하면 정수 1, 불가능하면 정수 0이다. 색 배치나 배치의 개수를 반환하지 않는다.

  • graph는 정사각 표이고 대칭이다. 자기 자신과의 연결은 없어 대각선은 0이다.
  • 연결되지 않은 두 점은 같은 색이어도 된다.
  • 점이 여러 덩어리로 나뉘어 있어도 모든 점을 칠한다.

삼각형에 두 색과 세 색을 쓸 때

삼각형, 두 색
세 점이 모두 서로 연결된 삼각형, k=2

반환값: 0

마지막 점은 앞의 두 점 모두와 이웃하므로 남는 색이 없다.

삼각형, 세 색
같은 삼각형, k=3

반환값: 1

세 점에 서로 다른 색을 칠하면 된다.

떨어진 점도 있음
0–1만 연결되고 2는 혼자인 그래프, k=2

반환값: 1

0과 1만 다르게 칠하면 된다. 2는 어느 색이나 가능하다.

색을 모두 쓸 필요 없음
점 하나, k=3

반환값: 1

한 색만 사용해도 조건을 만족한다.

연결된 두 점, 한 색
선 하나로 연결된 두 점, k=1

반환값: 0

양 끝의 색을 다르게 할 수 없다.

색을 정하기 전에 이미 칠한 이웃을 본다

삼각형에서 0번을 빨강으로 칠했다면 1번은 빨강을 쓸 수 없다. 1번을 파랑으로 칠한 뒤에는 2번에서 빨강과 파랑이 모두 막힌다. 세 번째 색이 있으면 성공하고, 없으면 앞의 선택으로 돌아간다. 코드의 color[v]=0은 방금 칠한 색을 지우는 줄이다.

C 함수의 인자
int can_color(const int graph[][8], int n, int k)

graph는 연결 표, n은 정점 수이다. 실제로는 앞의 n행·n열을 사용한다.

7-4 서로 공격하지 않는 퀸의 배치 수 · 도전문제

n×n 체스판에 퀸 n개를 놓는다. 퀸은 같은 행, 같은 열, 같은 대각선에 있는 다른 퀸을 공격한다. 어느 두 퀸도 서로 공격하지 않도록 놓아야 한다.

조건을 만족하는 배치의 수를 정수로 반환하시오.

nqueen_count(n)

입력

n
체스판의 한 변 길이이자 퀸 수. 1~8의 정수

반환값과 조건

가능한 배치 수를 반환한다. 가능한 배치가 없으면 0이다.

  • 한 칸에는 퀸 하나만 놓는다.
  • 회전하거나 뒤집은 모양도 퀸이 놓인 칸이 다르면 다른 배치로 센다.
  • 퀸 n개를 n개의 행에 서로 공격하지 않게 놓으면 각 행과 열에 하나씩 놓이게 된다.

작은 체스판에서 답이 없는 경우

한 칸
n=1

반환값: 1

유일한 칸에 퀸 하나를 놓는다.

두 줄
n=2

반환값: 0

행과 열을 다르게 놓아도 같은 대각선에 놓이게 된다.

세 줄
n=3

반환값: 0

세 퀸을 모두 충돌 없이 놓는 배치가 없다.

네 줄
n=4

반환값: 2

위에서부터 2,4,1,3열인 배치와 그 좌우 대칭 배치를 각각 센다.

다섯 줄
n=5

반환값: 10

조건을 만족하는 서로 다른 열 선택이 열 가지이다.

행 차이와 열 차이가 같으면 대각선이다

(1행,2열)과 (2행,3열)은 행과 열이 모두 한 칸 차이이므로 같은 대각선이다. 코드는 퀸을 한 행에 하나씩 놓아 같은 행 검사를 생략한다. 앞 행의 퀸과 열이 같은지, 행 차이와 열 차이의 절댓값이 같은지를 검사한다.

int nqueen_count(int n)

8-1 주어진 방문 순서의 왕복 비용 · 아주 쉬움

구할 값

route에 적힌 순서대로 도시를 방문하고, 출발한 0번 도시로 돌아올 때까지 드는 비용의 합을 구하세요.

도시는 0번부터 n−1번까지 있습니다. dist는 도시 사이의 이동 비용을 적은 표이고, route는 방문할 순서입니다.

route_cost(dist, route)

입력

dist
n행 n열의 비용 표입니다. n은 도시 수이며 1~9입니다. 행은 출발 도시, 열은 도착 도시입니다. 예를 들어 dist[0][1]은 0번에서 1번으로 가는 비용입니다.
route
도시 번호를 방문 순서대로 적은 길이 n의 배열입니다. 첫 값은 0이고, 모든 도시 번호가 한 번씩 들어 있습니다. [0,1,2]이면 0번, 1번, 2번 순서입니다.

반환값

마지막 도시에서 0번으로 돌아오는 비용까지 포함한 총비용을 정수 하나로 반환합니다.

계산 규칙

  • 각 이동 비용은 0~100인 정수이고, 같은 도시로 가는 대각선 값은 0입니다. 모든 도시 사이를 이동할 수 있습니다.
  • dist의 행 번호와 열 번호는 모두 0번부터 셉니다. 반대 방향의 비용은 다를 수 있으므로 각각 표에서 읽습니다.
  • 방문 순서는 입력받은 route를 따릅니다. 마지막 원소 다음에는 route의 첫 원소인 0번으로 돌아옵니다.
  • 도시가 하나이면 dist=[[0]], route=[0]이고 반환값은 0입니다.
예제 1 · PPTX 예제 · 0번 → 1번 → 2번 → 0번
dist = [
  [0, 2, 8],
  [1, 0, 3],
  [4, 6, 0]
]
route = [0, 1, 2]

반환값 9

0→1은 2, 1→2는 3, 2→0은 4입니다. 2+3+4=9를 반환합니다.

예제 2 · 방문 순서가 0번 → 2번 → 1번일 때
dist = [
  [0, 2, 8],
  [1, 0, 3],
  [4, 6, 0]
]
route = [0, 2, 1]

반환값 15

0→2는 8, 2→1은 6, 1→0은 1입니다. 8+6+1=15를 반환합니다.

예제 3 · 두 도시의 왕복
dist = [
  [0, 5],
  [8, 0]
]
route = [0, 1]

반환값 13

0→1의 비용 5와 1→0의 비용 8을 더합니다. 5+8=13입니다.

예제 4 · 도시가 하나일 때
dist = [
  [0]
]
route = [0]

반환값 0

0번 도시에서 시작해 그대로 끝납니다. dist[0][0]=0이므로 반환값은 0입니다.

풀이 힌트

route=[0,1,2]이면 dist[0][1], dist[1][2], dist[2][0]을 더합니다. i는 route에서 읽을 위치입니다. 현재 도시는 route[i], 다음 도시는 route[(i+1)%n]입니다. 마지막 위치의 다음 위치는 0이 됩니다.

8-2 남은 작업 비용의 하한 계산 · 쉬움

구할 값

아직 작업을 맡기지 않은 사람마다, 남은 작업 중 가장 싼 비용을 하나씩 찾아 더하세요.

사람 n명과 작업 n개가 있고 번호는 각각 0번부터 n−1번까지입니다. 앞의 몇 사람에게는 작업을 이미 맡겼습니다. 이 함수는 앞으로 드는 비용을 낮게 잡아 보는 계산입니다. 이렇게 실제 비용보다 작거나 같게 잡은 값을 하한이라고 합니다.

assignment_bound(cost, used, next_row)

입력

cost
n행 n열의 비용 표이며 n은 1~8입니다. cost[r][c]는 사람 r에게 작업 c를 맡길 때 드는 비용입니다. 행은 사람, 열은 작업이며 번호는 0번부터 셉니다.
used
길이 n의 작업 사용 표시입니다. used[c]=1이면 작업 c를 이미 맡겼고, 0이면 남아 있습니다. [0,1,0]이면 작업 1만 사용한 상태입니다.
next_row
다음에 작업을 맡길 사람 번호입니다. 0번부터 next_row−1번 사람은 배정이 끝났으며, next_row번부터 마지막 사람까지 계산합니다.

반환값

남은 각 사람의 최소 비용을 더한 값을 정수 하나로 반환합니다. 이미 배정한 사람에게 든 비용은 이 합에 넣지 않습니다.

계산 규칙

  • 각 비용은 0~100인 정수입니다. next_row는 0~n이며, used에서 값이 1인 칸의 개수와 같습니다.
  • 각 사람의 행에서 used가 0인 작업 열만 살펴보고, 그중 가장 작은 비용을 고릅니다.
  • 이 하한 계산에서는 서로 다른 사람이 같은 작업 열의 값을 골라도 됩니다. 한 행을 계산한 뒤에도 used는 그대로 둡니다.
  • next_row=0이면 모든 사람을 계산하고, next_row=n이면 남은 사람이 없으므로 0을 반환합니다.
예제 1 · PPTX 예제 · 작업 1을 이미 맡긴 상태
cost = [
  [9, 2, 7],
  [6, 4, 3],
  [5, 8, 1]
]
used = [0, 1, 0]
next_row = 1

반환값 4

사람 0의 배정은 끝났으므로 사람 1과 2만 봅니다. 작업 1의 열은 제외합니다. 사람 1은 min(6,3)=3, 사람 2는 min(5,1)=1이므로 3+1=4입니다. 두 값 모두 작업 2의 비용이어도 허용합니다. 사람 0에게 이미 든 비용 2는 더하지 않습니다.

예제 2 · 아무 작업도 맡기지 않은 상태
cost = [
  [9, 2, 7],
  [6, 4, 3],
  [5, 8, 1]
]
used = [0, 0, 0]
next_row = 0

반환값 6

세 사람을 모두 봅니다. 각 행의 최소 비용은 2, 3, 1이므로 2+3+1=6입니다. 사람 1과 2가 같은 작업 2의 값을 골라도 이 계산에서는 허용합니다.

예제 3 · 모든 사람의 배정이 끝난 상태
cost = [
  [9, 2, 7],
  [6, 4, 3],
  [5, 8, 1]
]
used = [1, 1, 1]
next_row = 3

반환값 0

n=3이고 next_row=3이므로 남은 사람이 없습니다. 더할 비용이 없어 0을 반환합니다.

예제 4 · 남은 사람이 한 명인 상태
cost = [
  [7]
]
used = [0]
next_row = 0

반환값 7

사람 0에게 남은 작업은 작업 0 하나입니다. 그 비용 7을 반환합니다.

풀이 힌트

PPTX의 used=[0,1,0], next_row=1에서는 작업 1의 열을 제외합니다. 사람 1은 min(6,3)=3, 사람 2는 min(5,1)=1이므로 하한은 4입니다. 실제로 서로 다른 작업을 맡기면 남은 비용은 7 또는 8입니다. 4는 이 실제 비용보다 낮게 잡은 값입니다.

C 함수의 입력
int assignment_bound(const int cost[][8], int n, const int used[], int next_row)

cost는 비용 표이고 n은 실제 사람 수이자 작업 수입니다. cost[][8]의 앞 n행·n열을 사용합니다. used[c]는 작업 c의 사용 표시이며, next_row는 계산을 시작할 사람 번호입니다.

8-3 작업을 중복 없이 배정하는 최소 비용 · 기본

구할 값

모든 사람에게 서로 다른 작업을 하나씩 맡겼을 때, 총비용을 가장 작게 만드는 배정의 비용을 구하세요.

사람 n명과 작업 n개가 있고 번호는 각각 0번부터 n−1번까지입니다. 모든 사람이 작업 하나씩을 맡아야 하며, 각 작업도 정확히 한 사람이 맡아야 합니다.

assignment_min(cost)

입력

cost
n행 n열의 비용 표이며 n은 1~8입니다. cost[r][c]는 사람 r에게 작업 c를 맡길 때 드는 비용입니다. 행은 사람, 열은 작업이고 번호는 0번부터 셉니다.

반환값

규칙을 지키는 모든 배정 중에서 총비용의 최솟값을 정수 하나로 반환합니다.

계산 규칙

  • 각 비용은 0~100인 정수입니다. 비용이 0인 작업도 정상적으로 맡길 수 있습니다.
  • 사람마다 작업 하나를 맡기고, 같은 작업을 두 사람에게 맡기지 않습니다.
  • 선택한 사람·작업 칸들의 비용을 모두 더해 총비용을 구합니다. 반환할 것은 최소 비용입니다.
  • 사람이 한 명이면 유일한 작업의 비용을 반환합니다.
예제 1 · PPTX 예제 · 세 사람의 최소 배정 비용
cost = [
  [9, 2, 7],
  [6, 4, 3],
  [5, 8, 1]
]

반환값 9

사람 0→작업 1의 비용은 2, 사람 1→작업 0의 비용은 6, 사람 2→작업 2의 비용은 1입니다. 서로 다른 작업을 사용했고 합은 9입니다. 가능한 여섯 배정의 총비용은 14, 20, 9, 10, 21, 16이므로 최솟값은 9입니다.

예제 2 · 두 사람의 배정을 비교하기

  [4, 1],
  [2, 3]
]

반환값 3

사람 0→작업 0, 사람 1→작업 1이면 4+3=7입니다. 반대로 맡기면 1+2=3입니다. 더 작은 3을 반환합니다.

예제 3 · 두 사람의 가장 싼 작업이 겹칠 때

  [1, 8],
  [2, 9]
]

반환값 10

1과 2는 둘 다 작업 0의 비용이어서 함께 고를 수 없습니다. 가능한 배정은 1+9=10 또는 8+2=10입니다. 최소 비용은 10입니다.

예제 4 · 모든 비용이 0일 때
cost = [
  [0, 0],
  [0, 0]
]

반환값 0

서로 다른 작업을 하나씩 맡기면 두 비용의 합이 0입니다.

예제 5 · 사람과 작업이 하나씩일 때
cost = [
  [7]
]

반환값 7

사람 0이 작업 0을 맡는 한 가지 배정만 가능합니다. 비용 7을 반환합니다.

풀이 힌트

사람 0부터 차례로 작업을 고르고, 고른 작업은 used에 표시합니다. 다음 사람의 탐색을 마치고 돌아오면 표시를 지워 다른 배정도 봅니다. 완성된 배정 중 가장 싼 비용을 best에 기억합니다. 현재 비용이 이미 best 이상이면 그 갈래를 멈출 수 있습니다. 남은 비용도 모두 0 이상이기 때문입니다.

C 함수의 입력
int assignment_min(const int cost[][8], int n)

cost는 비용 표이고 n은 실제 사람 수이자 작업 수입니다. cost[][8]의 앞 n행·n열을 사용합니다. 함수는 모든 사람의 작업을 고른 뒤 최소 총비용을 반환합니다.

8-4 모든 도시를 방문하는 최소 왕복 비용 · 추가 연습

구할 값

0번 도시에서 출발해 모든 도시를 한 번씩 방문하고 0번으로 돌아오는 경로 중, 총비용이 가장 작은 경로의 비용을 구하세요.

도시는 0번부터 n−1번까지 있습니다. 다음에 방문할 도시의 순서도 직접 골라야 합니다. dist는 도시 사이의 이동 비용을 적은 표입니다.

입력

dist
n행 n열의 비용 표이며 n은 도시 수이고 1~9입니다. dist[i][j]는 i번 도시에서 j번 도시로 가는 비용입니다. 행은 출발 도시, 열은 도착 도시이고 번호는 0번부터 셉니다.

계산 규칙

  • 각 이동 비용은 0~100인 정수이고 대각선은 0입니다. 모든 도시 사이를 이동할 수 있습니다. 반대 방향의 비용은 다를 수 있습니다.
  • 출발점은 0번으로 고정합니다. 나머지 도시를 각각 한 번씩 방문하고 마지막에만 0번으로 돌아옵니다.
  • 방문 순서별 총비용을 비교해 가장 작은 비용을 반환합니다.
  • 도시가 하나이면 추가로 이동할 곳이 없으므로 0을 반환합니다.
예제 1 · PPTX 예제 · 두 방문 순서를 비교하기

]

  [0, 5],
  [8, 0]
]

반환값 13

가능한 왕복은 0→1→0입니다. 가는 비용 5와 돌아오는 비용 8을 더해 13을 반환합니다.

예제 3 · 모든 이동 비용이 0일 때
dist = [
  [0, 0, 0],
  [0, 0, 0],
  [0, 0, 0]
]

반환값 0

어느 순서로 방문해도 모든 이동 비용이 0이므로 최소 총비용도 0입니다.

예제 4 · 도시가 하나일 때

]

풀이 힌트

C 함수의 입력
int tsp_min(const int dist[][9], int n)

dist는 비용 표이고 n은 실제 도시 수입니다. dist[][9]의 앞 n행·n열을 사용합니다. 출발점은 0번이며, 모든 도시를 방문한 뒤 0번으로 돌아오는 최소 비용을 반환합니다.

이 문제 연습하기

9장 NP완전 문제

9-1 주어진 선택의 합 확인 · 아주 쉬움

정수 배열 a와 같은 길이의 선택 표시 selected가 주어진다. selected[i]=1이면 a[i]를 골랐고, 0이면 고르지 않았다. 이미 고른 원소들의 합이 target과 같은지 검사한다.

고른 원소의 합이 target이면 1, 다르면 0을 반환하시오.

verify_subset_sum(a, selected, target)

입력

a
길이 0~20인 배열. 각 원소는 0~100의 정수
selected
a와 길이가 같은 0/1 배열
target
검사할 목표 합. 0~2000의 정수

반환값과 조건

검사 결과인 정수 1 또는 0을 반환한다. 원소의 합 자체를 반환하지 않는다.

  • 선택 표시를 바꾸거나 다른 부분집합을 새로 찾지 않는다.
  • 선택한 원소가 없을 때의 합은 0이다.
  • 값이 0인 원소를 선택해도 합은 변하지 않는다.

다른 선택으로 목표를 만들 수 있어도 현재 선택만 검사한다

고른 합이 목표와 같음
a=[1,2,3], selected=[1,0,1], target=4

반환값: 1

선택된 첫째와 셋째 값의 합은 1+3=4이다.

목표만 다름
같은 a와 selected, target=5

반환값: 0

선택 합은 여전히 4이므로 목표 5와 다르다.

선택을 새로 찾지 않음
a=[1,2,3], selected=[0,0,0], target=3

반환값: 0

값 3이 배열에 있어도 선택되지 않았다. 현재 합은 0이다.

빈 선택과 목표 0
a=[], selected=[], target=0

반환값: 1

빈 합 0이 목표와 같다.

0을 선택함
a=[0], selected=[1], target=0

반환값: 1

선택한 값 0의 합도 0이다.

표시가 1인 원소만 더한다

선택 표시가 이미 주어졌으므로 가능한 선택들을 탐색할 필요가 없다. 배열을 한 번 읽으며 표시가 1인 값만 합에 더한다. 마지막에 이 합을 target과 비교한다. 7장의 부분집합 합 찾기와 달리, 여기서는 제시된 답 하나를 검사한다.

C 함수의 인자
int verify_subset_sum(const int a[], const int selected[], int n, int target)

a는 값 배열, selected는 선택 표시이다. 두 배열의 길이는 n이다.

9-2 주어진 정점 커버 확인 · 쉬움

그래프에서 점을 몇 개 골랐다. 각 선의 양 끝 중 적어도 한 점을 골랐으면 그 선을 덮었다고 한다. 모든 선을 덮는 점들의 선택을 정점 커버라고 한다.

selected가 모든 선을 덮고 있으면 1, 덮지 못한 선이 있으면 0을 반환하시오.

verify_vertex_cover(graph, selected)

입력

graph
점 1~8개의 대칭인 0/1 연결 표. 대각선은 0
selected
점 수와 같은 길이. 점 i를 골랐으면 1, 아니면 0

반환값과 조건

주어진 선택이 정점 커버이면 1, 아니면 0이다. 선택한 점의 수를 반환하지 않는다.

  • 선의 양 끝을 모두 골라도 그 선을 덮은 것이다.
  • 점의 개수가 최소인지까지 검사하지 않는다.
  • 선이 하나도 없으면 덮지 못한 선도 없으므로 1이다.

점 하나로 못 덮는 삼각형의 남은 선

삼각형에서 두 점 선택
삼각형의 점0과 점1을 선택

반환값: 1

0–1,0–2,1–2 모두 선택한 끝점이 있다.

삼각형에서 한 점만
같은 삼각형에서 점0만 선택

반환값: 0

1–2 선은 양 끝을 모두 고르지 않아 덮지 못한다.

전부 선택
삼각형의 세 점을 모두 선택

반환값: 1

최소 개수는 아니어도 모든 선을 덮는다.

선이 없음
두 점 사이에 선이 없고 아무 점도 고르지 않음

반환값: 1

검사해야 할 선이 없어 조건을 만족한다.

두 끝을 모두 고르지 않은 선 하나면 실패한다

삼각형에서 점0만 고르면 0–1과 0–2는 덮는다. 하지만 1–2는 양 끝이 모두 미선택이므로 실패한다. 코드에서는 연결된 두 점을 읽고, 두 선택 표시가 모두 0이면 바로 0을 반환한다. 끝까지 이런 선이 없으면 1이다.

C 함수의 인자
int verify_vertex_cover(const int graph[][8], int n, const int selected[])

graph는 연결 표, n은 정점 수, selected는 길이 n인 선택 표시이다.

9-3 주어진 해밀턴 순회 확인 · 기본

모든 점을 정확히 한 번씩 방문한 뒤 출발점으로 돌아오는 순회를 해밀턴 순회라고 한다. 연결 표 graph와 방문 순서 path를 받아 이 순서가 올바른 해밀턴 순회인지 검사한다.

번호·중복·이동 연결을 모두 만족하면 1, 하나라도 어기면 0을 반환하시오.

verify_hamiltonian(graph, path)

입력

graph
점 수 n이 3~8인 대칭 0/1 연결 표. 대각선은 0
path
길이 n의 정수 배열. 잘못된 번호나 중복 번호가 들어올 수 있음

반환값과 조건

올바른 순회이면 정수 1, 아니면 정수 0이다.

  • 모든 번호는 0~n−1 범위여야 하고 중복되면 안 된다.
  • path에서 연속한 두 점 사이와 마지막·첫 점 사이에 모두 선이 있어야 한다.
  • 시작점은 0이 아니어도 된다. path의 끝에는 시작점을 한 번 더 적지 않는다.

중복 방문과 마지막 귀환을 따로 검사한다

네 점을 한 바퀴
0–1–2–3–0인 사각형, path=[0,1,2,3]

반환값: 1

모든 점을 한 번씩 방문하고 3–0으로 돌아온다.

다른 점에서 출발
같은 사각형, path=[2,3,0,1]

반환값: 1

시작점이 2여도 모든 조건을 만족한다.

중복 번호
같은 사각형, path=[0,1,1,3]

반환값: 0

1을 두 번 방문하고 2를 빠뜨렸다.

범위 밖 번호
같은 사각형, path=[0,1,2,9]

반환값: 0

점 번호는 0~3인데 9가 들어 있다.

귀환할 선이 없음
0–1–2–3만 연결된 일자 그래프, path=[0,1,2,3]

반환값: 0

중간 이동은 가능하지만 마지막 3–0 선이 없다.

순서에 등장한 점과 이동한 선을 확인한다

먼저 path의 번호가 범위 안에 있는지와 중복 여부를 본다. 이 검사를 통과하면 점들은 빠짐없이 한 번씩 들어 있다. 이어서 실제 이동에 필요한 선들을 확인한다. 마지막 점에서 첫 점으로 돌아가는 선도 같은 방법으로 검사해야 한다.

C 함수의 인자
int verify_hamiltonian(const int graph[][8], int n, const int path[])

graph는 연결 표, n은 정점 수, path는 길이 n인 방문 순서이다.

9-4 세 항짜리 논리 조건의 만족 가능성 · 조금 도전

변수 x₁부터 xₙ에 각각 0(거짓) 또는 1(참)을 넣는다. 조건 하나는 정수 세 개로 표현한다. 양수 k는 xₖ의 값이고, 음수 −k는 xₖ의 값을 뒤집은 것이다. 한 조건의 세 값 중 하나라도 1이면 그 조건을 통과한다.

모든 조건을 동시에 통과하는 값 배정이 존재하면 1, 없으면 0을 반환하시오.

satisfiable_3cnf(n, clauses)

입력

n
변수 수. 1~12의 정수
clauses
길이 0~30의 조건 목록. 각 조건은 0이 아닌 정수 세 개이며 1≤|항|≤n

반환값과 조건

가능한 값 배정이 하나라도 있으면 1, 전혀 없으면 0이다. 배정 목록을 반환할 필요는 없다.

  • 한 조건 안에서는 OR, 조건들 사이는 AND로 연결한다. 이런 형식을 3-CNF라고 한다.
  • 예를 들어 [1,−2,3]은 x₁, 뒤집은 x₂, x₃ 중 하나라도 참이면 통과한다.
  • 같은 항이 한 조건에 여러 번 나올 수 있다. 조건 목록이 비었으면 1이다.

한 조건을 통과하는 것과 모든 조건을 통과하는 것

참으로 만들 수 있는 조건
n=1, clauses=[[1,1,1]]

반환값: 1

x₁=1이면 세 항이 모두 1이어서 통과한다.

서로 충돌하는 두 조건
n=1, clauses=[[1,1,1],[-1,-1,-1]]

반환값: 0

첫 조건은 x₁=1, 둘째는 x₁=0을 요구하므로 동시에 통과할 수 없다.

음수 항의 역할
n=2, clauses=[[1,−2,1]]

반환값: 1

x₁=0, x₂=0이면 −2의 값은 1이므로 이 조건을 통과한다.

조건이 없음
n=2, clauses=[]

반환값: 1

위반할 조건이 없으므로 어떤 배정이나 가능하다.

변수 두 개면 네 배정을 검사한다

변수가 두 개이면 (x₁,x₂)는 (0,0),(1,0),(0,1),(1,1)의 네 경우이다. 배정 하나를 정할 때마다 모든 조건을 검사한다. 조건 하나라도 실패하면 다음 배정을 보고, 모두 통과한 배정이 나오면 1을 반환한다. n이 12 이하이므로 최대 4096개 배정을 확인한다.

C 함수의 인자
int satisfiable_3cnf(int n, const int clauses[][3], int m)

n은 변수 수, m은 조건 묶음 수이다. clauses의 각 행에는 항 3개를 넣는다.

10-1 최적 비용의 허용 배수 확인 · 아주 쉬움

비용이 작을수록 좋은 문제에서, 이미 구한 해의 비용 cost와 최적 비용 opt가 주어진다. cost가 opt의 factor배 이내인지 검사한다. 최적 비용을 새로 구할 필요는 없다.

cost≤opt×factor이면 1, 아니면 0을 반환하시오.

within_factor(cost, opt, factor)

입력

cost
구한 해의 비용. 1~1,000,000의 정수
opt
알려진 최적 비용. 1≤opt≤cost
factor
허용하는 배수. 1~100의 정수

반환값과 조건

허용 범위 안이면 정수 1, 범위를 넘으면 정수 0이다.

  • 허용 비용과 정확히 같을 때도 1이다.
  • factor=1이면 최적 비용과 같아야 통과한다.

정확히 두 배인 비용도 허용한다

두 배보다 작음
cost=18, opt=10, factor=2

반환값: 1

허용 비용은 20이고 18은 그 이하이다.

경계와 같음
cost=20, opt=10, factor=2

반환값: 1

20≤20이므로 통과한다.

경계를 넘음
cost=21, opt=10, factor=2

반환값: 0

21은 허용 비용 20을 초과한다.

최적 비용과 같음
cost=10, opt=10, factor=1

반환값: 1

최적 비용 자체이므로 통과한다.

1배 조건에서 더 비쌈
cost=11, opt=10, factor=1

반환값: 0

허용 비용 10보다 크다.

나누지 않고 허용 비용과 비교한다

최적 비용이 10이고 두 배를 허용하면 허용 비용은 20이다. cost를 20과 비교하면 된다. 정수 나눗셈으로 cost/opt를 먼저 구하면 소수 부분을 버려 경계를 잘못 판단할 수 있다. 곱셈과 이하 비교로 직접 계산한다.

C 함수의 인자
int within_factor(int cost, int opt, int factor)

세 인자는 Python과 같은 뜻이다.

10-2 가장 한가한 기계에 작업 맡기기 · 쉬움

같은 성능의 기계 m대가 시간 0부터 준비되어 있다. 작업 시간 배열 jobs를 앞에서부터 읽으며, 누적 작업 시간이 가장 작은 기계에 그 작업을 맡긴다. 누적 시간이 같으면 번호가 작은 기계를 고른다.

아래 배정 규칙대로 모든 작업을 맡긴 뒤, 전체 작업이 끝나는 시각을 반환하시오.

list_scheduling(jobs, m)

입력

jobs
길이 0~1000의 작업 시간 배열. 각 시간은 0~1,000,000
m
기계 수. 1~10의 정수. 번호는 0~m−1

반환값과 조건

기계별로 맡긴 시간의 합 중 최댓값을 반환한다. 기계들의 완료 시각을 모두 더하지 않는다.

  • 작업의 입력 순서를 바꾸지 않는다. 한 작업을 여러 기계로 나눌 수 없다.
  • 각 기계는 자신에게 배정된 작업을 받은 순서대로 계속 처리한다.
  • 작업이 없으면 완료 시각은 0이다.

작업 순서를 바꾸면 답도 달라진다

3,2,4 순서
jobs=[3,2,4], m=2

반환값: 6

기계별 합은 [3,6]이다. 둘 다 끝나는 시각은 6이다.

4,3,2 순서
jobs=[4,3,2], m=2

반환값: 5

기계별 합은 [4,5]이다. 같은 작업들이어도 입력 순서가 달라 답은 5이다.

기계 한 대
jobs=[3,2,4], m=1

반환값: 9

한 기계가 세 작업을 모두 처리한다.

동점 발생
jobs=[2,2,2], m=2

반환값: 4

마지막 작업 직전 합이 [2,2]라 번호가 작은 기계0에 맡긴다.

작업 없음
jobs=[], m=3

반환값: 0

어느 기계에도 작업을 맡기지 않는다.

기계별 합 [3,2]에서 4를 어디에 맡길까

첫 작업 3은 기계0, 다음 작업 2는 기계1에 맡긴다. 이때 기계별 누적 시간은 [3,2]이다. 마지막 작업 4는 합이 더 작은 기계1에 맡겨 [3,6]이 된다. 기계0은 시각 3에, 기계1은 시각 6에 끝나므로 전체 완료 시각은 6이다.

C 함수의 인자
int list_scheduling(const int jobs[], int n, int m)

jobs는 작업 시간 배열, n은 작업 수, m은 기계 수이다.

10-3 선의 양 끝을 고르는 정점 커버 · 기본

무방향 그래프의 선들을 주어진 순서대로 확인한다. 이번 선의 양 끝 점을 모두 아직 고르지 않았다면 두 점을 함께 고른다. 한쪽이라도 이미 골랐다면 그 선에서는 아무 점도 추가하지 않는다.

이 절차가 끝난 뒤 선택한 점의 개수를 반환하시오.

cover_size(n, edges)

입력

n
점 수. 1~100의 정수. 번호는 0~n−1
edges
0~1000개의 [끝점1,끝점2] 쌍. 두 끝점은 서로 다름

반환값과 조건

위 절차로 선택한 점의 수를 반환한다. 최솟값을 찾기 위해 절차를 바꾸지 않는다.

  • 선의 입력 순서를 유지한다. 순서가 바뀌면 고른 점의 수도 달라질 수 있다.
  • 같은 선이 목록에 다시 나와도 이미 고른 점은 한 번만 센다.
  • 선과 연결되지 않은 점은 선택할 필요가 없다. 선이 없으면 답은 0이다.

같은 그래프도 선의 순서에 따라 선택 수가 달라진다

반환값: 2

선 없음

반환값: 0

점이 네 개 있어도 고른 점은 없다.

10-4 새 원소를 가장 많이 덮는 집합 선택 · 조금 도전

전체 원소는 0부터 n−1까지이다. 여러 집합 중 아직 덮지 못한 원소를 가장 많이 포함하는 집합을 하나 고른다. 새로 덮는 수가 같으면 입력에서 먼저 나온 집합을 고른다. 고른 집합의 원소를 덮음으로 표시하고 이 과정을 반복한다.

모든 원소를 덮으면 선택한 집합 수, 끝까지 덮을 수 없으면 −1을 반환하시오.

greedy_set_cover(n, sets)

입력

n
전체 원소 수. 1~20의 정수
sets

반환값과 조건

정해진 선택 절차의 횟수를 반환한다. 가능한 모든 조합 중 최소 집합 수를 구하는 문제는 아니다.

  • n=4일 때 3은 {0,1}, 6은 {1,2}, 12는 {2,3}을 나타낸다. 0은 빈 집합이다.
  • 이미 덮은 원소는 새로 덮는 수에 포함하지 않는다.
  • 남은 원소가 있는데 어느 집합도 새 원소를 덮지 못하면 −1이다.

반환값: 1

A={0,1}, B={1,2}, C={2,3}이면 처음에는 세 집합 모두 두 원소를 덮는다. A를 고른 뒤 남은 원소는 2와 3이다. 이때 B는 원소2 한 개, C는 원소2와3 두 개를 새로 덮으므로 C를 고른다. 비트마스크는 이 포함 여부를 정수의 0/1 자리로 적은 표현이다.

11-1 상하좌우 이동 거리 · 아주 쉬움

장애물이 없는 격자의 출발점 (x1,y1)에서 도착점 (x2,y2)로 간다. 한 번에 상·하·좌·우 중 한 방향으로 한 칸 움직인다. 대각선 이동은 허용하지 않는다.

manhattan(x1, y1, x2, y2)

입력

x1, y1
출발점 좌표. 각각 −10,000~10,000의 정수
x2, y2
도착점 좌표. 각각 −10,000~10,000의 정수

반환값과 조건

최소 이동 횟수 |x1−x2|+|y1−y2|를 정수로 반환한다.

  • 좌표가 음수여도 같은 격자의 점이다. 거리에는 좌표 차이의 절댓값을 쓴다.
  • 두 점이 같으면 이동하지 않아 답은 0이다.

같은 점
출발과 도착이 모두 (2,3)

반환값: 0

이동할 필요가 없다.

음수 좌표 포함
출발 (2,−1), 도착 (−2,2)

반환값: 7

가로 |2−(−2)|=4, 세로 |−1−2|=3으로 합은 7이다.

대각선 방향
출발 (0,0), 도착 (1,1)

반환값: 2

오른쪽과 위로 한 번씩 가야 한다. 한 번에 대각선으로 갈 수 없다.

x좌표 차이는 가로로 움직여야 하는 칸 수이고 y좌표 차이는 세로 칸 수이다. 왼쪽이나 아래로 가면 차이가 음수가 될 수 있지만 이동 횟수는 음수가 될 수 없다. 두 차이의 절댓값을 더한다. 이런 거리를 맨해튼 거리라고 부른다.

11-2 가까운 도시부터 방문하는 순회 · 쉬움

0번 도시에서 출발한다. 현재 도시에서 아직 방문하지 않은 도시 중 이동 비용이 가장 작은 곳으로 간다. 비용이 같으면 번호가 작은 도시를 고른다. 모든 도시를 방문하면 0번으로 돌아온다.

이 선택 규칙을 그대로 실행한 왕복 비용을 반환하시오.

nearest_neighbor(dist)

입력

dist
도시 1~9개의 정사각 비용 표. 값은 0~100, 대각선은 0

반환값과 조건

가까운 도시부터 방문한 경로의 비용을 정수로 반환한다. 모든 순서를 비교한 최솟값과 다를 수 있다.

  • 모든 이동이 가능하며 방향별 비용은 달라도 된다.
  • 이미 방문한 도시는 다음 후보에서 뺀다. 마지막 귀환 비용은 더한다.
  • 도시가 하나이면 0이다.

가까운 선택을 반복해도 전체 최적 경로와 다를 수 있다

기본 순회
dist=[[0,3,1],[3,0,2],[1,2,0]]

반환값: 6

0에서 2를 고르고 1로 간 뒤 귀환해 1+2+3=6이다.

동률은 작은 번호
dist=[[0,1,1],[5,0,1],[2,7,0]]

반환값: 4

0에서 1과2의 비용이 같아 1을 먼저 고른다. 비용은 1+1+2=4이다.

가까운 선택의 한계
dist=[[0,1,2,9],[1,0,1,9],[2,1,0,50],[9,9,50,0]]

반환값: 61

규칙의 경로 0,1,2,3,0은 61이다. 더 싼 경로가 있어도 규칙대로 계산한 61을 반환한다.

두 도시
dist=[[0,5],[8,0]]

반환값: 13

왕복 비용 5+8이다.

도시 하나
dist=[[0]]

반환값: 0

추가로 방문할 도시가 없다.

네 도시 사례에서는 0에서 비용1인 1을 고르고, 1에서 비용1인 2를 고른다. 남은 3으로 가는 비용은 50이어서 전체 비용은 61이 된다. 0,2,1,3,0은 비용21이지만, 이 함수는 전체 최적 경로를 찾는 함수가 아니라 주어진 가까운 도시 선택 규칙을 구현한다.

11-3 새 후보를 받아들일지 판단하기 · 기본

비용을 줄이는 과정에서 현재 해를 새 후보로 바꿀지 결정한다. 후보 비용이 현재보다 작거나 같으면 항상 받아들인다. 더 비싼 후보는 온도 temp와 주어진 숫자 u를 사용해 아래 규칙으로 판단한다.

새 후보를 받아들이면 1, 거부하면 0을 반환하시오.

accept_move(current, candidate, temp, u)

입력

current, candidate
현재 비용과 새 후보 비용. 각각 0~10,000의 정수
temp
온도. 0~1000의 실수
u
비교에 쓸 숫자. 0 이상 1 미만의 실수

반환값과 조건

수락 여부인 정수 1 또는 0을 반환한다. 새 비용을 반환하지 않는다.

  • candidate≤current이면 temp와 u에 관계없이 1이다.
  • candidate>current이고 temp=0이면 0이다.
  • 더 비싸고 temp>0이면 p=exp((current−candidate)/temp)를 계산한다. u<p이면 1, 그 외에는 0이다.
  • 새 난수를 만들지 말고 입력 u를 쓴다. 양의 온도에서 u=0이면 수락한다.

같은 후보도 온도와 u에 따라 판단이 달라진다

더 싼 후보
current=10, candidate=8, temp=0, u=0.9

반환값: 1

비용을 줄이므로 온도가 0이어도 받아들인다.

비용이 같음
current=10, candidate=10, temp=0, u=0.99

반환값: 1

같은 비용도 첫 조건에 따라 수락한다.

더 비싸고 온도 0
current=10, candidate=12, temp=0, u=0

반환값: 0

온도 0에서 더 비싼 후보는 거부한다. u=0이어도 이 조건이 먼저이다.

작은 u
current=10, candidate=12, temp=2, u=0.2

반환값: 1

p=exp(−1)≈0.368이고 0.2<p이다.

큰 u
같은 비용과 온도, u=0.8

반환값: 0

0.8은 약 0.368보다 크므로 거부한다.

온도 2
current=10, candidate=12, temp=2, u=0.5

반환값: 0

0.5는 수락 확률 약 0.368보다 크다.

온도만 4로 변경
current=10, candidate=12, temp=4, u=0.5

반환값: 1

p=exp(−0.5)≈0.607로 커져 이번에는 수락한다.

좋은 후보부터 처리하고 나눗셈은 나중에 한다

조건의 순서가 중요하다. 좋은 후보나 같은 비용의 후보는 먼저 수락하고, 남은 경우에서 온도가 0인지 확인한다. 그다음에만 확률식을 계산하므로 0으로 나누지 않는다. exp는 지수 함수이며 Python의 math.exp, C의 math.h에 있는 exp를 사용한다. 이 한 단계의 판단은 담금질 기법에서 쓰는 수락 규칙이다.

C 함수의 인자
int accept_move(int current, int candidate, double temp, double u)

temp와 u는 double형이다. 나머지 조건은 Python과 같다.

11-4 도시 두 위치를 한 번 교환한 최소 비용 · 조금 도전

도시를 방문하는 원래 경로 route가 주어진다. 첫 위치의 도시0은 그대로 두고, 나머지 위치 중 두 곳을 골라 한 번 맞바꾼다. 아무것도 바꾸지 않은 원래 경로도 후보로 포함한다.

이 후보들의 왕복 비용 중 가장 작은 값을 반환하시오.

best_swap_cost(dist, route)

입력

dist
도시 1~9개의 정사각 비용 표. 각 값 0~100, 대각선 0
route
0으로 시작하며 0~n−1을 한 번씩 포함하는 길이 n의 배열

반환값과 조건

원래 경로 또는 한 번 교환한 경로의 최소 비용을 반환한다. 바꾼 경로 자체는 반환하지 않는다.

  • 모든 이동이 가능하고 방향별 비용은 달라도 된다. 마지막 귀환 비용도 포함한다.
  • 각 후보는 원래 경로에서 새로 만든다. 한 번 좋아진 경로에서 계속 교환을 누적하지 않는다.
  • 두 위치를 고를 수 없으면 원래 비용을 반환한다. 입력 route의 내용도 바꾸지 않는다.

반환값: 10

2와3의 위치를 바꾼 [0,1,3,2]의 비용은 10이다. 원래 비용은 23이다.

dist=[[0,1,9],[4,0,2],[3,6,0]], route=[0,1,2]

원래 비용은 1+2+3=6이고, 교환하면 9+6+4=19라 그대로 둔다.

같은 표, 다른 시작 경로
같은 dist, route=[0,2,1]

반환값: 6

1과2의 위치를 바꾸면 앞 사례의 비용6인 경로가 된다.

교환할 두 위치가 없음
dist=[[0,5],[8,0]], route=[0,1]

반환값: 13

첫 위치를 고정하면 남은 위치가 하나뿐이라 원래 비용을 반환한다.

도시 하나
dist=[[0]], route=[0]

반환값: 0

바꿀 위치도 없고 왕복 비용도 0이다.

후보 하나를 계산한 뒤 원래 순서로 돌린다

[0,1,2,3]에서 바꿀 수 있는 위치 쌍은 (1,2),(1,3),(2,3)이다. 각 쌍을 바꾼 비용을 계산한 다음 같은 두 위치를 다시 바꿔 복구한다. 복구하지 않으면 다음 후보가 원래 경로에서 두 번 바뀐 경로가 되어 문제의 조건과 달라진다.

dist는 비용 표, n은 도시 수, route는 길이 n인 방문 순서이다.
