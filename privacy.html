방문 통계 수집 안내 / Visit analytics

시행: 2026-09-19 · 운영자: 박상돈 · 문의: sangdonpark@dju.kr

수집 목적과 항목

사이트 이용 현황 파악과 운영 개선을 위해 방문 시각, 페이지 경로, 유입 사이트 도메인, 브라우저·기기 종류, 서버에서 확인되는 접속 IP를 수집합니다. 고유 방문 통계를 위해 브라우저 저장소에 임의 식별자를 저장하고 서버에는 변환된 식별자를 보관합니다. 쿼리 문자열·검색어·입력 내용·학생 이름·학번·답안 코드는 이 통계에 수집하지 않습니다.

보관과 접근

원본 IP는 30일, 나머지 방문 기록과 브라우저 식별자는 최대 365일 보관합니다. 만료 데이터는 매시간 정리합니다. Supabase의 기존 서울 리전 프로젝트에 저장하며 사이트 관리자만 접속 기록을 조회할 수 있습니다. IP는 공유망이나 VPN 주소일 수 있으며 특정 개인의 신원을 뜻하지 않습니다.

수집 해제

아래 버튼으로 이 브라우저에서 새 방문 통계 전송을 중지할 수 있습니다. Do Not Track 또는 Global Privacy Control 신호가 켜진 브라우저에서도 전송하지 않습니다. 설정은 이 브라우저에만 적용됩니다. 다른 기기에서는 별도로 설정해야 합니다.

이 설정은 이번에 추가된 방문 통계에 적용됩니다. 기존 Google 태그 및 수업 실습의 학생 기록 저장과는 별도입니다. 이미 저장된 기록에 관한 문의는 위 운영자 이메일로 보내주세요.

English

We collect visit time, page path, referring domain, browser/device category and the connection IP received by our server for site analytics. A random browser ID is stored locally; a transformed ID is stored on the server. Query strings, form values, student identities and source code are not collected by this tracker. IP addresses are retained for 30 days; other visit records and browser identifiers for up to 365 days. Expired records are cleaned hourly. Records are stored in our Supabase Seoul project and are accessible only to the administrator.

The button above enables or disables this new tracker for this browser. DNT and GPC signals are respected. This setting is separate from existing Google tags and classroom progress records. Contact: sangdonpark@dju.kr.
