윈도우 사용자부터 갑니다. VS Code 안의 터미널(Ctrl+백틱)을 열고, 왼쪽 검은 박스의 첫 줄을 칩니다. setx 한 칸 띄고 GEMINI_API_KEY 한 칸 띄고 따옴표 안에 본인 키를 붙여 넣습니다. setx는 "환경변수를 영구히 저장하라"는 윈도우 명령입니다. Enter를 치면 "성공: 지정한 값을 저장했습니다"라는 메시지가 나옵니다. 그러면 등록된 겁니다.

여기서 매 학기 가장 많이 나오는 실수, 오른쪽 위 박스입니다. setx는 지금 열려 있는 터미널에는 적용되지 않습니다. 이미 켜져 있는 창은 옛날 설정을 기억하고 있어요. 그래서 반드시 터미널을 닫고 새로 열어서 확인해야 합니다. VS Code 터미널 오른쪽 위 휴지통 아이콘으로 닫고 다시 Ctrl+백틱.

새 터미널에서 확인 명령입니다. 터미널이 CMD 종류면 echo 퍼센트 GEMINI_API_KEY 퍼센트, PowerShell 종류면 echo 달러 env 콜론 GEMINI_API_KEY 입니다. 어느 쪽인지 모르겠으면 둘 다 쳐 보세요. 하나는 먹습니다. 본인 키 AIza…가 그대로 출력되면 통과입니다. 이름이 그대로 출력되거나 빈 줄이 나오면 새 터미널이 아니거나 오타입니다.

명령어가 불편하면 GUI로도 됩니다. 오른쪽 아래 박스. Windows 설정, 시스템, 정보, 고급 시스템 설정, 환경 변수, '사용자 변수'에서 새로 만들기, 변수 이름 GEMINI_API_KEY, 변수 값에 키. 효과는 동일합니다.

맥 사용자는 다음 장을 보세요. 윈도우 분들은 확인 끝나면 잠시 옆 사람을 도와주시면 됩니다.
