Cline을 연결합니다. 두 장입니다. 이번 장은 설치.

1번. 지난주에 확장을 설치했던 그 메뉴입니다. VS Code 왼쪽 세로 막대의 확장 아이콘, 또는 Ctrl+Shift+X. 검색창에 Cline이라고 치세요. 왼쪽 화면처럼 결과가 나오는데, 비슷한 이름이 많습니다. Cline Chinese, Cline Pro, Cline Nightly. 제작자가 'Cline'이고 이름 옆에 파란 체크가 있고 설치 수가 500만이 넘는 맨 위 항목이 정답입니다. 아래 작은 화면은 같은 확장을 마켓플레이스 웹사이트에서 본 모습인데, 참고만 하세요.

2번. Install을 누르면 잠시 후 왼쪽 세로 막대에 로봇 모양 아이콘이 하나 생깁니다. 그게 Cline입니다. 누르면 오른쪽 또는 사이드바에 Cline 패널이 열립니다.

3번, 여기가 헷갈리는 지점입니다. 처음 열면 Cline 계정을 만들어서 시작하라는 큰 버튼이 나옵니다. 그건 Cline 회사의 유료 서비스로 가는 길이라 우리는 안 씁니다. 그 아래에 'Use your own API key'(내 키를 쓰겠다)라는 글자를 찾아서 누르세요. 만약 그런 글자가 안 보이면 패널 오른쪽 위의 톱니바퀴 아이콘, 설정으로 들어가면 같은 화면이 나옵니다. Cline은 업데이트가 잦아서 첫 화면 모양이 조금씩 바뀝니다. 핵심은 "설정에서 내 키를 넣는다"입니다.

아래 박스, Cline이 뭐였는지 다시. VS Code 안에서 "이 파일 만들어 줘"라고 말하면 실제로 파일을 만들고 고쳐 주는 코딩 에이전트입니다. 그런데 Cline 자체에는 두뇌, 즉 AI 모델이 없습니다. 그래서 다음 장에서 Gemini API 키를 꽂아 줘야 움직입니다.

설치는 1분쯤 걸립니다. 로봇 아이콘이 안 보이면 VS Code를 재시작하세요.
