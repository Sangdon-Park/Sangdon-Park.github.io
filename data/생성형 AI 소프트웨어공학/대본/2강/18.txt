API 키를 만드는 페이지입니다. 왼쪽 그림은 실제 캡처가 아니라 화면 구성도입니다. 이 페이지는 로그인한 사람에게만 보여서 캡처를 넣을 수가 없었어요. 대신 버튼 이름과 위치를 실제와 같게 그려 뒀으니, 여러분 화면과 맞춰 보면서 따라 하면 됩니다.

1번. 페이지 오른쪽 위에 "+ Create API key" 버튼이 있습니다. 누르세요. 참고로 요즘은 처음 들어가면 구글이 키를 하나 자동으로 만들어 두는 경우도 있습니다. 목록에 이미 AIza로 시작하는 키가 있으면 그걸 써도 됩니다.

2번. 작은 창이 뜨면서 프로젝트를 고르라고 합니다. '프로젝트'는 구글이 키를 묶어 관리하는 단위인데, 지금은 신경 안 써도 됩니다. 목록에 나오는 것(보통 하나뿐입니다)을 고르세요. 아무것도 없으면 'Create project'로 하나 만들면 됩니다. 이름은 아무거나.

3번. "Create API key in existing project" 같은 버튼을 누르면 몇 초 뒤 키가 만들어집니다. AIza로 시작하는 39자짜리 긴 문자열입니다. 그게 여러분의 키입니다.

4번. 키 옆의 복사 아이콘을 누르면 복사됩니다. 일단 메모장을 열어서 붙여 두세요. 단! 다음 장을 보기 전까지는 이 키를 절대 아무 데도 올리지 않습니다. 카톡에도, 코드에도, 인터넷에도.

아래 박스, 비용 얘기를 미리 하면, 오늘 실습 정도는 무료 등급으로 됩니다. 다만 무료 등급은 한도가 있습니다. 제가 직접 재 보니 flash-lite는 분당 15회에 하루 500회, flash는 분당 5회에 하루 20회입니다. 하루 한도는 미국 태평양 시간 자정에 초기화되는데, 한국 시간으로는 오후 4시쯤(겨울에는 5시)입니다. 그래서 가끔 "잠깐 기다리라"는 메시지가 나오는데, 그건 요금이 아니라 속도 제한입니다. 결제 정보를 넣지 않는 한 돈이 나갈 일은 없습니다. 신용카드 안 넣습니다.

화면이 슬라이드와 조금 다르면 "Create API key"라는 글자를 찾으면 됩니다.
