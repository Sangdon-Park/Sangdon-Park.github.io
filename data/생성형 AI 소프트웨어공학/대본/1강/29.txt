GitHub Student Developer Pack, 줄여서 학생 팩입니다. 왼쪽 화면이 그 페이지, education.github.com/pack 입니다.

무엇을 주냐면, 학교 이메일로 재학생 인증을 하면 여러 유료 개발 도구를 재학 중 무료로 쓸 수 있습니다. 예를 들면 GitHub Copilot Pro(AI 코딩 도우미인데 원래 월 1만 원 넘습니다)라든가, JetBrains라는 회사의 전문가용 개발 도구 전체, 여러 클라우드 회사의 크레딧, 무료 도메인 같은 것들입니다. 목록은 자주 바뀌니까 페이지에서 직접 확인하세요.

신청 방법은 간단합니다. GitHub에 로그인한 상태로 이 주소에 들어가서 초록 버튼 "Sign up for Student Developer Pack"을 누르고, 학교 이메일을 인증하고, 학생증이나 재학증명서 사진을 올리면 됩니다. 며칠 안에 승인 메일이 옵니다. 신청 자체는 5분, 승인은 보통 1에서 7일입니다.

주의할 점 하나. GitHub 계정의 이메일에 학교 이메일이 등록되고 인증되어 있어야 합니다. 아까 학교 이메일로 가입했으면 그대로 되고, 개인 이메일로 가입했으면 설정에서 학교 이메일을 추가하면 됩니다.

이번 주 과제와는 무관하니, 오늘 실습이 끝나고 집에서 천천히 하세요. 주소를 못 외우겠으면 검색창에 'GitHub Student Pack'이라고 치면 첫 번째로 나옵니다.

자, 이제 오늘의 하이라이트로 갑니다. 저장소를 만들고 파일을 올립니다.
