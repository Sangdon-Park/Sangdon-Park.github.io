성공 확인은 간단합니다. 브라우저에서 내 저장소 페이지를 새로고침하세요. F5 키입니다. 왼쪽 화면처럼 파일 목록에 hello.py가 보이고, 목록 위 커밋 줄에 "first commit"이라는 메시지가 보이면 성공입니다. 이 화면은 예시로 제 강의 저장소를 띄운 것이라 파일 이름은 다르지만, 여러분 화면에는 README.md와 hello.py 두 개, 그리고 first commit이 보여야 합니다. 그게 여러분이 남긴 첫 번째 기록입니다. 축하합니다.

성공한 사람은 아래 초록 박스대로, 브라우저 주소창의 github.com/본인아이디/hello-sw 를 복사해서 LMS 1주차 게시판에 올리세요. 그게 오늘 출석 인증입니다.

잘 안 되는 경우는 세 가지가 대부분입니다. 오른쪽입니다.

첫째, 인증 창이 안 떠요. push를 쳤는데 브라우저가 안 열리는 경우입니다. 터미널을 보면 https://github.com/login/… 으로 시작하는 링크가 찍혀 있을 겁니다. 그 링크를 복사해서 브라우저 주소창에 직접 붙여 넣고 로그인하면 됩니다. 오른쪽 아래 그림이 그때 뜨는 로그인 화면입니다. 방금 만든 계정으로 로그인하고 Authorize.

둘째, push가 거부돼요. "403"이나 "permission denied" 같은 글자가 나오는 경우입니다. 십중팔구 clone한 주소가 본인 저장소가 아닌 경우입니다. 옆 사람 화면 보고 따라 하다가 옆 사람 주소를 복사하는 일이 실제로 자주 있습니다. 터미널에 git remote -v 를 치면 지금 연결된 주소가 나오는데, 아이디가 본인 것인지 확인하세요. 아니면 폴더를 지우고 본인 주소로 다시 clone합니다.

셋째, 한글이 깨져요. 파일에 한글을 넣었을 때 GitHub에서 이상한 글자로 보이는 경우인데, 파일 인코딩 문제입니다. VS Code 오른쪽 아래에 'UTF-8'이 보이면 정상이고, VS Code 기본값이 UTF-8이라 오늘은 거의 없을 겁니다.

시간이 남으면 hello.py를 터미널에서 python hello.py 로 실행해 보세요. 화면에 Hello, Software Engineering 이 찍히면 됩니다.
