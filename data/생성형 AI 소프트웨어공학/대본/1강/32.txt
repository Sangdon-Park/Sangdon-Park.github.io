오늘의 마지막 실습, 파일을 하나 만들어서 GitHub에 올립니다. 왼쪽이 파일 만들기, 오른쪽이 올리기입니다.

1번. VS Code에서 hello-sw 폴더가 열려 있어야 합니다. 방금 안 열었으면 메뉴 [파일, 폴더 열기]로 여세요.

2번. 왼쪽 탐색기에서 폴더 이름 HELLO-SW 위에 마우스를 올리면 오른쪽에 작은 아이콘 네 개가 나타나는데, 첫 번째가 '새 파일'입니다. 그걸 누르면 이름을 쓰는 칸이 생깁니다. hello.py 라고 치고 Enter. 마지막이 점 p y 입니다. 이 확장자가 "파이썬 파일"이라는 표시입니다. 그러면 왼쪽 그림처럼 탐색기에 hello.py가 생기고 오른쪽 편집기에 빈 파일이 열립니다. 아이콘을 못 찾겠으면 메뉴 [파일, 새 텍스트 파일]로 만들고 저장할 때 이름을 hello.py로 하면 됩니다.

3번. 편집기에 딱 한 줄을 칩니다. 아래 그림에 있는 그대로입니다. print, 소괄호 열고, 큰따옴표, Hello, Software Engineering, 큰따옴표 닫고, 소괄호 닫고. print는 "화면에 글자를 보여 줘"라는 파이썬 명령입니다. 다 쳤으면 Ctrl+S로 저장합니다. 저장하면 탭 이름 옆의 하얀 동그라미가 사라집니다. 하얀 동그라미는 '아직 저장 안 됨' 표시입니다.

이제 오른쪽, 올리기입니다. 터미널이 hello-sw 폴더 안에 있는 상태에서 세 명령을 한 줄씩 칩니다.

git add hello.py, add는 올릴 파일을 고르는 겁니다. "이 파일을 다음 기록에 포함하겠다"는 표시. 장바구니에 담는 것과 비슷합니다.

git commit -m "first commit", commit은 메시지를 붙여서 기록을 남기는 겁니다. 내 컴퓨터 안에 '사진 한 장'을 찍어 저장하는 것. -m 뒤 따옴표 안이 이 기록의 제목입니다. 오늘은 다 같이 first commit이라고 씁니다.

git push, push는 지금까지의 기록을 인터넷, 즉 GitHub 저장소로 올리는 겁니다. 이걸 해야 다른 사람, 다른 컴퓨터에서 보입니다.

왜 세 단계로 나뉘는지는 지금은 몰라도 됩니다. 쓰다 보면 이해되고, 필요한 순간에 다시 설명합니다. 오늘은 '고르고, 기록하고, 올린다' 세 단어만 기억하세요.

아래 분홍 박스. 첫 push 때 브라우저 창이 자동으로 뜹니다. "Sign in to GitHub" 화면이면 방금 만든 계정으로 로그인하고, "Authorize" 버튼이 나오면 누릅니다. 이건 "내 컴퓨터의 Git이 내 GitHub 계정에 올려도 된다"고 허락하는 절차입니다. 한 번만 하면 이후엔 묻지 않습니다. 창을 닫고 터미널로 돌아오면 push가 이어서 진행됩니다.

commit에서 "Please tell me who you are"라는 메시지가 나오면 아까 git config 단계를 안 한 것이니, 그 단계로 돌아가서 하면 됩니다.
