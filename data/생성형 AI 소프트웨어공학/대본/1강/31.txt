이제 GitHub에 있는 저장소를 내 컴퓨터로 가져옵니다. 이 동작을 clone, 복제라고 부릅니다. 저장소를 내 컴퓨터로 통째로 복사하는 것입니다.

왼쪽 화면은 예시로 제 강의 저장소를 띄운 것입니다. 이름은 다르지만 여러분의 hello-sw 저장소 페이지도 배치가 똑같으니 같은 자리를 누르면 됩니다.

1번. 저장소 페이지 오른쪽 위, 파일 목록 바로 위에 초록 "Code" 버튼이 있습니다. 클릭하면 작은 창이 펼쳐집니다.

2번. 펼쳐진 창에 "Clone"이라고 쓰여 있고, HTTPS와 GitHub CLI 탭이 있습니다. HTTPS 탭이 선택된 상태에서 그 아래 주소가 보입니다. https://github.com/아이디/hello-sw.git 형태입니다. 주소 오른쪽 끝의 네모 두 개 겹친 아이콘이 '복사' 버튼입니다. 그걸 누르면 주소가 복사됩니다. 혹시 SSH라는 탭이 보여도 그건 고르지 마세요. 오늘은 HTTPS입니다.

이제 VS Code 터미널로 돌아옵니다. 오른쪽 검은 박스입니다. git clone 한 칸 띄고, 방금 복사한 주소를 Ctrl+V로 붙여넣고 Enter. 슬라이드에는 ID라고 써 있는데 그 자리에 본인 아이디가 들어간 주소를 붙여넣는 겁니다. 몇 초 지나면 "Cloning into 'hello-sw'..." 하고 끝납니다. 그다음 cd hello-sw 를 치고 Enter. cd는 '폴더로 들어간다'는 명령입니다. 이제 터미널의 현재 위치가 hello-sw 폴더 안이 됩니다. 프롬프트 끝에 hello-sw가 붙어 있으면 성공입니다.

아래 박스, "그런데 어디에 복사됐나요?"라는 질문이 꼭 나옵니다. 터미널에 표시돼 있던 현재 폴더(보통 C:\Users\내이름) 안에 hello-sw 라는 폴더가 새로 생깁니다. 파일 탐색기로 가 보면 그 폴더 안에 README.md가 있을 겁니다.

그리고 이제 VS Code에서 그 폴더를 엽니다. 메뉴 [파일, 폴더 열기]에서 방금 생긴 hello-sw 폴더를 선택하면, VS Code 왼쪽 탐색기에 README.md가 보입니다. "이 폴더의 작성자를 신뢰합니까?"라는 창이 뜨면 '예, 작성자를 신뢰합니다'를 누르세요. 여러분이 만든 폴더니까요.

clone이 실패하면 주소를 잘못 붙여넣었거나 인터넷 문제입니다. 주소를 다시 복사해서 시도하세요.
