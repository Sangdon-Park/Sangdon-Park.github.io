# 취창업역량강화 발표 과제 운영안

발표 7분 + 질의응답 3분. 운영 시간과 평가는 담당 교수가 조정할 수 있습니다.

1. 실제 공고 1개를 고르고 원문·확인일·선택 이유를 제시합니다.
2. 핵심 요구 역량을 전공 과목 2개와 연결하고 실제 공부 결과를 설명합니다.
3. 자신의 프로젝트에서 맡은 부분과 문제 해결 1건을 실행·검사 증거로 설명합니다.
4. AI를 썼다면 사용 범위, 직접 판단·수정한 부분, 직접 검증한 내용을 말합니다.
5. 현재의 한계와 다음 주에 수행할 구체적인 준비 과제를 적습니다.

제출: 발표자료, 본인 포트폴리오 PDF, 코드/시연 링크, 준비 계획서.
프로젝트가 없다면 상태를 밝히고 작은 기능을 구현해 증거를 추가합니다.
계획을 수행 경험으로 기록하지 않습니다. 교수자의 경력을 자신의 이력으로 옮기지 않습니다.

| 평가 | 배점 |
|---|---:|
| 공고와 전공 연결 | 20 |
| 개인 기여와 구현 | 25 |
| 문제 해결과 검증 | 25 |
| AI 활용의 검토 | 15 |
| 발표와 다음 계획 | 15 |

AI 미사용자는 미사용 사유와 독립적인 판단·검증 과정으로 해당 항목을 평가합니다.
프로젝트 규모 자체보다 본인 경험을 근거로 설명하는지를 봅니다.
