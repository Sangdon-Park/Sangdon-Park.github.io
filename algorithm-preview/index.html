최댓값을 찾을 때의 비교 횟수

원문 발췌: 1강 연습문제 22번

A는 숫자 n개가 든 리스트이며 n≥1이다. 다음 Python 코드를 한 번 실행한다. A[i] > largest를 검사하는 횟수만 셀 때, 총 몇 번 검사하는가?

def get_largest(A):
    largest = A[0]
    for i in range(1, len(A)):
        if A[i] > largest:
            largest = A[i]
    return largest

유클리드 알고리즘 추적

원문 발췌: 3강 연습문제 77번

최대공약수를 구하는 유클리드 알고리즘은 b가 0이 아닐 동안 (a,b)를 (b,a%b)로 동시에 바꾼다. %는 a를 b로 나눈 나머지이며, b=0이면 a를 반환한다.

(18,12)에서 시작한다. 시작 쌍부터 종료할 때까지의 (a,b)를 순서대로 쓰고, 최종 최대공약수를 쓰시오.

순서대로 쓴 세 쌍에 각 1점, 최종 최대공약수에 1점입니다. 풀이 과정은 쌍의 변화로 보여 주면 됩니다.
